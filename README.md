# MathX

MathX é uma aplicação web desenvolvida em Laravel que permite criar uma variedade de exercícios de matemática com base em valores recebidos e um número selecionado de exercícios. Ele oferece funcionalidades para imprimir e exportar os exercícios gerados para um arquivo de texto.

## Funcionalidades

- **Gerar Exercícios**: Crie exercícios de matemática (adição, subtração, multiplicação, divisão) com valores e quantidade personalizados.
- **Imprimir Exercícios**: Visualize os exercícios em uma página pronta para impressão.
- **Exportar Exercícios**: Exporte os exercícios gerados para um arquivo de texto.

## Tecnologias Utilizadas

- **Laravel**: Framework PHP utilizado para construir a aplicação.
- **Bootstrap**: Biblioteca de CSS para estilização e design responsivo.
- **MVC**: Arquitetura de software utilizada para organizar a aplicação.
